# Навигатор будущего

Интерактивный квест для детей 9–14 лет: игровые ситуации помогают исследовать, какие занятия ребёнку интересны, познакомиться с примерами профессий и выбрать небольшой проект для самостоятельной пробы.

## Состав проекта

- `public/index.html` — адаптивное веб-приложение на русском языке. Включает 9 игровых миссий, карту выборов, примеры профессий, идеи проектов и печать результата в PDF.
- `worker.js` — Cloudflare Worker, который отдаёт статические файлы из папки `public`.
- `wrangler.toml` — конфигурация Cloudflare Workers Static Assets.
- `package.json` — команды локального запуска, проверки и публикации.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run check
npm run dev
```

Открой локальный адрес, который покажет Wrangler.

## Проверка перед публикацией

```bash
npm run check
npm run test:e2e
```

Playwright проверяет стартовый экран, прохождение всех 9 миссий, карту интересов, отмену ответа, возврат к предыдущей миссии, мобильную раскладку и действие печати PDF. Для первого запуска тестов браузер Chromium должен быть установлен командой `npx playwright install chromium`.

## Публикация

```bash
npx wrangler login
npm run deploy
```

Перед публикацией проверь имя Worker в `wrangler.toml` и убедись, что вход выполнен в нужный аккаунт Cloudflare. После деплоя открой выданный адрес на компьютере и телефоне.

## Что умеет квест

- 9 ситуаций с понятным сюжетом и несколькими осмысленными вариантами действий.
- Пять направлений интереса: исследование, создание, техника, общение и организация.
- Результат показывает выборы в этой игре, а не диагноз или «оценку способностей».
- Примеры профессий, варианты применения ИИ и небольшие проекты для пробы.
- Адаптивный интерфейс для телефона и компьютера.
- Печать карты интересов или сохранение в PDF через системное окно печати.
- Повторное прохождение без сохранения персональных данных на сервере.

## Важное ограничение

Это игровой инструмент для разговора и исследования интересов, а не валидированный профориентационный тест и не психологическая диагностика. Ответы зависят от контекста и могут меняться по мере нового опыта. Не используйте результат, чтобы ограничивать выбор ребёнка.

## Визуальная концепция

Единый стиль проекта: приключенческая книжка для детей 9–14 лет, лисёнок Фокс как постоянный проводник, глубокий синий и фиолетовый, бирюзовые акценты и тёплый жёлтый для ключевых действий. Иллюстрации должны сохранять единый дизайн персонажа, мягкий объёмный свет и ясную композицию. Полный документ концепции: `docs/ART_DIRECTION.md`.
