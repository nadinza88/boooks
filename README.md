# Книжная мастерская NeuroGym

Веб-приложение для создания детских иллюстрированных историй. Интерфейс на русском языке, акварельно-гуашевый стиль, чтение книги, локальная библиотека и экспорт через системное окно печати в PDF.

## Что входит

- `public/index.html` — frontend и деморежим с двумя готовыми сюжетами.
- `worker.js` — API-маршруты `/api/status`, `/api/story`, `/api/image`.
- `wrangler.toml` — конфигурация Cloudflare Workers и статических assets.
- `package.json` — команды запуска и проверки.
- `.dev.vars.example` — безопасный пример без секретов.

## Требования

- Node.js 20 или новее (рекомендуется LTS).
- Аккаунт Cloudflare для публикации.
- Доступ к Cloudflare Workers AI и включённый binding `AI` для генерации текста и изображений.

## Локальный запуск

1. Распакуй ZIP в отдельную папку.
2. Установи Node.js LTS, если он ещё не установлен.
3. Открой терминал в папке проекта и выполни:

   ```bash
   npm install
   npm run check
   npm run dev
   ```

4. Открой локальный URL, который покажет Wrangler. Без AI binding приложение должно открыться в деморежиме.
5. Для теста реального ИИ выполни `npx wrangler login`, затем настрой Workers AI binding в Cloudflare. Не вставляй ключи в frontend.

## Публикация на Cloudflare Workers

1. Выполни `npm install`.
2. Войди: `npx wrangler login`.
3. Проверь конфигурацию `wrangler.toml` и имя проекта `neurogym-storybook`.
4. Убедись, что Workers AI доступен аккаунту. В Cloudflare Dashboard открой Worker → Settings → Bindings → Add binding → Workers AI; имя переменной должно быть `AI`. В конфигурации Wrangler binding описан как `AI`.
5. Выполни `npm run deploy`.
6. Открой выданный URL и проверь `/api/status`.

## Модели ИИ

По умолчанию настроены:
- Текст: `@cf/qwen/qwen3-30b-a3b-fp8`
- Изображения: `@cf/black-forest-labs/flux-1-schnell`

Доступность моделей и тарификация зависят от актуального каталога и состояния аккаунта Cloudflare. Перед использованием в классе проверь, что обе модели доступны и квоты достаточны. Если модель снята или недоступна, замени её ID в начале `worker.js` на актуальную совместимую модель из каталога Workers AI.

## Локальное хранение

Книги сохраняются в `localStorage` браузера (до 30 книг на устройство). Они не синхронизируются между устройствами и могут быть удалены при очистке данных браузера. Для важных книг используй экспорт PDF.

## Экспорт PDF

Нажми «Сохранить в PDF» и в диалоге печати выбери «Сохранить как PDF». Экспорт включает обложку, текст и доступные изображения. Перед сохранением дождись завершения генерации иллюстраций, если они нужны в PDF.

## Проверка основных сценариев

- [ ] `/api/status` отвечает JSON и корректно показывает наличие binding.
- [ ] Без binding интерфейс работает в деморежиме.
- [ ] Пустая идея не запускает создание книги.
- [ ] Создание демо-книги и перелистывание работают.
- [ ] Книга появляется в «Мои книги» после создания и открывается повторно.
- [ ] Удаление книги удаляет её только из локальной библиотеки.
- [ ] PDF открывает системный диалог печати.
- [ ] На мобильном экране книга становится одностраничной.
- [ ] При `prefers-reduced-motion: reduce` анимации сокращаются.
- [ ] С ошибкой генерации изображения история остаётся доступна, повтор генерации предлагается на странице без картинки.
- [ ] Реальная генерация текста и изображений проверена после подключения AI binding.

## Ограничения текущей версии

- Демо-режим использует заранее подготовленные сюжеты и не создаёт уникальные изображения; интерфейс не выдаёт их за генерацию ИИ.
- Облачная публикация, реальные модели и PDF-печать требуют проверки в конкретном аккаунте и браузере.
- Общей базы данных, аккаунтов пользователей и синхронизации между устройствами нет.
- Перед использованием детьми взрослому следует протестировать приложение и проверить актуальные лимиты/условия моделей.


## Дизайн v2
Обновлённая адаптивная верстка: разворот ограничен доступной высотой экрана, на телефоне страницы идут вертикально, сохранены акварельные иллюстрации и плавное перелистывание. Вызов FLUX исправлен: параметр `seed` удалён, так как модель его отклоняла.


## Обновление дизайна

В этой версии обновлены адаптивные размеры книжного разворота, отступы от рамки, оформление обложки с иллюстрацией первой страницы, мобильная вёрстка и типографика. Обложка использует уже созданную иллюстрацию первой страницы, поэтому не требует дополнительного запроса к модели. Вызовы FLUX не передают неподдерживаемый параметр `seed`.
